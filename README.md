# HeaLX MEDI CLINIC Website

A responsive static website for HeaLX MEDI CLINIC.

## Files
- `index.html` — page content
- `style.css` — design and responsive layout
- `script.js` — mobile navigation and footer year

## GitHub Pages
1. Create a GitHub repository.
2. Upload these three files to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save and wait for the Pages URL to appear.

## Before giving this to the clinic
Confirm all medical claims, doctor credentials, services, hours, phone number, address, social links, and consultation wording with the clinic.

The current site intentionally does not invent testimonials, medical outcomes, emergency-service capabilities, or patient information.
